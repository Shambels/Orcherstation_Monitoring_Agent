Ce qu'il faut retenir

  

    
1 · DEUX VECTEURS
Chaque morceau est rangé deux fois
Un vecteur dense de 384 nombres pour le sens (MiniLM multilingue), un vecteur creux BM25 français pour les mots exacts. Avec Modifier.IDF, Qdrant pondère lui-même les mots rares.

    
2 · LA FUSION
RRF additionne des rangs, pas des scores
Chaque liste donne 1 / (position + 2). Un morceau bien placé dans les deux listes gagne. Si une liste est vide, l'autre suffit.

    
3 · LE FILTRE
Le code écarte les articles internes
public_seulement=True pose un filtre sur metadata.visibilite, appliqué dans Qdrant pendant la recherche. KB-019 n'arrive jamais à l'assistant N1.

    
4 · LE RÉFLEXE
Vérifier la recherche avant le LLM
Si le bon article n'est pas dans le top-k, aucun prompt ne sauvera la réponse. Et avec un morceau par article, seule la meilleure section passe.
